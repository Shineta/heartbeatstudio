# Heartbeat Studio — Beta Testing Guide

## PHASE 1: ACCOUNT & AUTHENTICATION

1. Visit the landing page — review hero section, feature cards, and pricing tiers
2. Click through all navigation links on the landing page
3. Register a new account with email and password — verify Terms of Service checkbox is required
4. Log out completely
5. Log back in with email and password
6. Log out again
7. Request a magic link login — check your email, click the link, verify you're logged in
8. Log out
9. Sign in with Google OAuth — verify your name and profile image appear
10. Log out and sign back in to confirm session persistence

## PHASE 2: DASHBOARD

11. Review dashboard layout: loved ones section, upcoming celebrations, creation stats
12. Verify all navigation links from the dashboard work
13. Confirm the dashboard updates as you create content throughout testing

## PHASE 3: LOVED ONES MANAGEMENT

14. Add a loved one with all fields filled: name, nickname, relationship, birthday (MM-DD), interests, inside jokes, avatar
15. Add a second loved one with minimal info (just name and relationship)
16. Edit the first loved one — change their nickname and interests
17. Verify changes are saved and reflected on the dashboard
18. Delete the second loved one — confirm deletion prompt and removal

## PHASE 4: SONG CREATION — LOVED ONES TAB

19. Start creating a song: select a loved one, pick an occasion, choose a tone and genre
20. Submit and wait for the song to generate — verify loading/progress indicators appear
21. Once generated: play the audio, read the lyrics, view the cover art
22. Use "Try Again" with the "Change Genre" option — pick a different genre and regenerate
23. Use "Try Again" with the "Give Feedback" option — write what you'd like changed and regenerate
24. Use "Try Again" with the "Edit Lyrics" option — modify lyrics and regenerate
25. Create a second song with a completely different occasion, tone, and genre

## PHASE 5: SONG CREATION — BUSINESS TAB

26. Switch to the Business tab
27. Create a business-themed song (e.g., employee appreciation, client thank you)
28. Play the generated audio and review lyrics

## PHASE 6: SONG CREATION — EDUCATION TAB

29. Switch to the Education tab
30. Create an education-themed song (e.g., student encouragement, teacher appreciation)
31. Play the generated audio and review lyrics

## PHASE 7: EXPERIENCE KITS

32. Start the Date Night Experience — generate all 3 romantic songs, verify emotional progression
33. Start the Birthday Blast Experience — generate all 5 birthday songs
34. Start the Gospel Greeting Experience — generate 2 gospel-inspired messages, verify scripture references
35. Start the Classroom Cheers Experience — generate all 5 group songs
36. Start the Sung Prayer Experience — generate 3 prayer songs, verify the structure (Thanksgiving, Declaration, Promises)
37. For each kit: play every song, read lyrics, check cover art

## PHASE 8: GREETING CARD — AI GENERATED COVER

38. Start creating a greeting card in the Loved Ones tab
39. Select "AI Generated" as the cover image source
40. Fill in recipient, occasion, tone, and message
41. Submit and verify the AI-generated cover image and card message appear
42. View the completed card

## PHASE 9: GREETING CARD — FAMILY PORTRAIT COVER

43. Select "Family Portrait" as the cover image source
44. Upload 2-6 photos of different people
45. Wait for face detection — verify detected faces appear with selection checkboxes
46. Select which people to include
47. Choose a scene category (Holidays) and specific scene (Christmas)
48. Choose a style (e.g., Watercolor)
49. Toggle "Keep original outfits" off — verify the output changes clothing
50. Toggle "Keep original outfits" on — verify original clothing is preserved
51. If any person has braces, test the "Remove braces" checkbox
52. Generate the portrait and review the result
53. After creating the portrait card, use "Same People, New Scene" — try at least 3 quick presets: Christmas Card, Vacation Postcard, Studio Portrait, Birthday Cartoon, Watercolor Art, Classic Painting
54. Verify each preset uses the same faces without re-uploading photos

## PHASE 10: GREETING CARD — FESTIVE TRANSFORM COVER (LOVED ONES TAB)

55. Select "Festive Transform" as the cover image source
56. Upload a single person's photo
57. Test the **Holidays** scene — generate with Christmas, then try Diwali, then Lunar New Year
58. Test the **Life Events** scene — generate with Birthday, then Graduation
59. Test the **Seasons** scene — generate with Winter Wonderland, then Summer Beach
60. Test the **Professional** scene — generate with Corporate Headshot, then LinkedIn Profile
61. Test **Blast from the Past** — generate with Fresh Prince Style, then 1980s Neon
62. For a TV show style, check the "Include TV show characters" checkbox and generate
63. Test the **Gaming** scene — generate with Gaming Moments, then 2K Player Card, then Minecraft
64. For each generation: verify the person's face is preserved and the scene matches the selection
65. Add custom instructions in the text area and verify they influence the result

## PHASE 11: GREETING CARD — FESTIVE TRANSFORM (BUSINESS TAB)

66. Switch to Business tab, select Festive Transform
67. Upload a professional photo
68. Test Professional Celebration scene with at least 2 styles
69. Test Milestone Moment scene
70. Test Team Celebration scene
71. Test Gaming scene — try 2K Player Card and Battle Royale styles
72. Verify all results look business-appropriate

## PHASE 12: GREETING CARD — FESTIVE TRANSFORM (EDUCATION TAB)

73. Switch to Education tab, select Festive Transform
74. Upload a student or teacher photo
75. Test Student Celebration scene with at least 2 styles
76. Test Academic Achievement scene
77. Test Graduation scene
78. Test Gaming scene — try Minecraft and Roblox styles
79. Verify all results are school-appropriate

## PHASE 13: GREETING CARD — GAMING CARD COVER (ALL TABS)

80. **Loved Ones tab**: Select "Gaming Card" as cover source
81. Set Scene to any option, Game Style to "2K Player Card"
82. Fill in all player details: username, overall rating, position, team, stats
83. Upload a player photo
84. Click "Generate Gaming Card" — verify loading state appears
85. Once generated: verify the card shows the correct face, basketball uniform, team name spelled correctly, rating, position, and stats
86. Click the generated image — verify it opens full screen and you can scroll to see the entire card
87. Click "Regenerate" — verify a new version is generated
88. Clear the card and regenerate with "Battle Royale (Fortnite)" style — verify Fortnite-themed UI
89. Test "GTA / Street Style" — verify urban/GTA aesthetic
90. Test "Minecraft" — verify blocky pixel art style
91. Test "Roblox" — verify colorful Roblox world
92. Test "Retro Arcade" — verify 8-bit pixel art arcade style
93. Test without a photo uploaded — verify the card still generates properly
94. **Business tab**: Repeat steps 81-85 with business-appropriate details
95. **Education tab**: Repeat steps 81-85 with student details — verify the card generates in all tabs

## PHASE 14: GREETING CARD — UPLOAD & NO IMAGE

96. Select "Upload Image" as cover source — upload a custom image, verify it appears as the card cover
97. Remove the uploaded image — verify it clears properly
98. Select "No Image" — create a card without any cover, verify it submits successfully

## PHASE 15: SONG ATTACHMENT TO CARDS

99. Create a greeting card and attach a previously generated song to it
100. View the completed card — verify the song plays when the card is opened
101. Create a card with multiple songs attached if supported

## PHASE 16: ANIMATION CREATION

102. Create a celebration animation — enter a description and select a style (cartoon)
103. Wait for generation — verify progress/status updates appear
104. Once complete, play the animation video
105. Create another animation with a different style (anime, 3D, watercolor, pixar, or realistic)
106. Verify each style produces visually distinct results

## PHASE 17: SCHEDULING & DELIVERY

107. Create a card or song and schedule it for a future date and time
108. Verify the scheduled creation appears on your dashboard with the correct date
109. Check that the scheduled status shows correctly (draft, scheduled, sent)

## PHASE 18: SHARING

110. Generate a shareable link for a completed creation
111. Copy the link and open it in a private/incognito browser window (not logged in)
112. Verify the shared creation loads and displays correctly to an unauthenticated viewer
113. If the creation has a song, verify audio playback works on the shared link
114. If the creation has an animation, verify video playback works on the shared link

## PHASE 19: CREDITS & PAYMENTS

115. Check your current credit balance on the dashboard
116. Review the pricing page — verify all three tiers display correctly: Free (3 credits), Credit Pack ($4.99 for 5 credits — "Most Popular"), Subscription ($10/month for 15 credits — "Best Value")
117. Purchase a Credit Pack through Stripe — complete the payment flow
118. After purchase, verify your credit balance increased by 5
119. Purchase a Subscription — complete the payment flow
120. Verify subscription status is active and credits are updated
121. Create content and verify credits are deducted correctly per creation
122. Attempt to create something with zero credits — verify a clear message appears directing you to purchase more

## PHASE 20: ADMIN DASHBOARD

123. Log in as an admin user
124. Navigate to /admin
125. Verify user statistics display: total users, 7-day signups, 30-day signups, active subscribers, marketing opt-ins
126. Search for a specific user by name or email
127. Filter users by marketing opt-ins
128. Filter users by subscribers
129. Export filtered user data as CSV — open the file and verify the data is correct
130. Log in as a non-admin user and try navigating to /admin — verify you're redirected away

## PHASE 21: CROSS-PLATFORM & EDGE CASES

131. Test the entire app on a mobile phone — check that layouts, forms, and navigation work on small screens
132. Test on a tablet — check the 2-column grid patterns
133. Test on desktop at various window sizes
134. Upload an extremely large image (10MB+) — verify graceful handling
135. Upload a non-image file where an image is expected — verify error message
136. Submit forms with empty required fields — verify validation messages
137. Test with a very long name/text in all input fields — verify layout doesn't break
138. Rapidly click "Generate" buttons — verify no duplicate submissions
139. Navigate away during a generation and come back — verify state is handled properly
140. Test with slow internet (use browser dev tools throttling) — verify timeouts and errors are handled gracefully
