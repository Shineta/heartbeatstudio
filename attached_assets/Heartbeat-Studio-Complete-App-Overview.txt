Heartbeat Studio - Complete App Overview

What is Heartbeat Studio?
Heartbeat Studio by Horton's Tech Innovations is an AI-powered celebration platform that helps users create personalized gifts for the people they care about. It enables anyone to generate custom AI songs, greeting cards, family portraits, festive photo transformations, and celebration animations — then share or schedule them for delivery at meaningful moments.

Core Concept
Instead of searching for generic gifts, users answer a few simple questions about their recipient and the platform's AI creates one-of-a-kind songs, cards, and animations personalized with real names, relationships, inside jokes, and occasions. Every creation comes with a shareable link so recipients can experience their gift instantly on any device.

Categories
Heartbeat Studio supports three creator categories:

1. Loved Ones — Personal celebrations for family, friends, and partners
2. Business — Professional greetings, team celebrations, and client appreciation
3. Education — Academic content through music, classroom celebrations, and learning songs

Authentication and Security
Three sign-in methods:
  - Email and Password with secure bcrypt hashing
  - Passwordless Magic Links sent via email (SendGrid)
  - Google OAuth 2.0 for one-click sign-in
Session fixation protection via session regeneration on all auth flows
One-time use magic link tokens
Secure httpOnly cookies
Password reset via SMS (Twilio) with email fallback
Phone number verification to prevent duplicate accounts
Terms of Service acceptance required during registration

Technical Stack

Frontend
React 18 with TypeScript
Vite for fast development and hot module replacement
Shadcn/ui component library (New York variant) with Radix UI primitives
Tailwind CSS with custom warm, joyful design tokens
TanStack Query (React Query) for server state management
Wouter for lightweight client-side routing
React Hook Form with Zod validation
Typography: Inter (primary) and Fredoka (accent/celebratory moments)
Responsive design: 1-column mobile, 2-3 columns tablet/desktop

Backend
Node.js with Express.js
TypeScript with full type safety
PostgreSQL database (Neon serverless) with WebSocket support
Drizzle ORM for type-safe database access
Passport.js for multi-method authentication
Session storage in PostgreSQL via connect-pg-simple

Key Integrations
Suno API: AI song generation with vocals, music, lyrics, and cover art (V5 model)
OpenAI (GPT-5): Text generation for card messages, song lyrics, and AI questionnaires
OpenAI (GPT-Image-1): Visual generation for card illustrations and cover art
Nano Banana API: Family portrait generation, festive photo transformations, greeting card images
Runway API: Text-to-video celebration animation generation
Stripe: Secure payment processing for credit packs, subscriptions, and experience kits
SendGrid: Magic link emails, scheduled delivery emails, and notifications
Twilio: SMS-based password reset and delivery notifications
Google Cloud Storage: Object storage for all generated media assets
Google OAuth: One-click sign-in via Google accounts

Design System

User Journey
1. Discover the platform via the landing page with feature showcase
2. Try a free song or card preview without signing up
3. Create an account (email, magic link, or Google sign-in)
4. Accept Terms of Service
5. Add loved ones with their names, relationships, birthdays, and interests
6. Choose what to create: song, card, animation, mixtape, or experience kit
7. Answer a few simple questions — AI handles the rest
8. Preview your creation and use Try Again if you want changes
9. Share via unique link or schedule for delivery at the perfect moment
10. Track all creations and celebrations from your dashboard
