Below is a clear UI blueprint + feature set for both tabs, designed so:

Users instantly recognize how to use them

The experience feels professional and appropriate

You avoid feature bloat while staying powerful

🔁 Core Principle (Very Important)

Business and Education should feel like “modes,” not new products.

That means:

Same layout

Same tools (Card, Animation, Song, Mixtape)

Different labels, defaults, guardrails, and examples

This keeps cognitive load low and development sane.

🧭 GLOBAL TAB STRUCTURE (Same for All 3)

Top navigation stays identical:

[Loved Ones]   [Business]   [Education]


Secondary navigation (unchanged):

Card | Animation | Song | Mixtape


When switching tabs:

Forms stay structurally the same

Field names, helper text, presets change
