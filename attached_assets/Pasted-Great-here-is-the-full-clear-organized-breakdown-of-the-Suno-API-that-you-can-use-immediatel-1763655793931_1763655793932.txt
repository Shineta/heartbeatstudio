# 🔧 1. **WHAT THE SUNO API CAN DO**

According to the documentation, the Suno API supports:

### **✔ Text-to-Music Generation**

* Generate full songs using a text prompt
* Supports *vocals* + *music track*
* Customize genre, style, mood
* Choose model version (v3.5, v4, v4.5PLUS, v5)

### **✔ Lyrics Generation**

* Generate lyrics only
* Structured lyrics output (verse, chorus, bridge)

### **✔ Audio Processing**

* Convert audio to WAV
* Separate vocals / instruments
* Improve quality / reprocess tracks

### **✔ Music Video Generation**

* Auto-create a short video based on the song generated
* Good for social sharing or your animation feature

### **✔ Commercial Use**

Documentation says:

> “Watermark-Free Commercial Use”

This makes it suitable for your scheduled-send “song gifts” app.

# 🚀 2. **KEY ENDPOINTS YOU’LL USE**

Here are the main endpoints relevant to your app:

## **A. Generate Music**

**POST** `/suno-api/generate-music`

### Parameters:

| Parameter        | Description                                   |
| ---------------- | --------------------------------------------- |
| **prompt**       | Your song description (required)              |
| **style**        | Genre (pop, R&B, lo-fi, etc.)                 |
| **lyrics**       | Optional custom lyrics                        |
| **model**        | Choose model version                          |
| **duration**     | Length of track                               |
| **low_vram**     | Reduce processing load (optional)             |
| **audio_format** | `wav` or `mp3` (mp3 recommended for your app) |

---

## **B. Generate Lyrics**

**POST** `/suno-api/generate-lyrics`

### Parameters:

| Key           | Description                          |
| ------------- | ------------------------------------ |
| **prompt**    | Theme of the lyrics                  |
| **style**     | Mood (romantic, funny, uplifting)    |
| **structure** | Song structure (verse/chorus/bridge) |

---

## **C. Generate Music Video**

**POST** `/suno-api/generate-music-video`

### Parameters:

| Key           | Description                   |
| ------------- | ----------------------------- |
| **audio_url** | The URL to the generated song |
| **prompt**    | Style of the video            |
| **model**     | Video generation model        |

# 🧪 3. **EXAMPLE REQUEST – Generate a Song**

### **Node.js Example**

```javascript
import axios from "axios";

const SUNO_API_KEY = process.env.SUNO_API_KEY;

async function generateSong() {
  const response = await axios.post(
    "https://api.sunoapi.org/suno-api/generate-music",
    {
      prompt: "A cute, loving birthday song for Jasmine with a soft R&B feel. Mention how much she loves sunflowers and dancing.",
      style: "cute rnb",
      model: "v4_5PLUS",
      duration: 45,
      audio_format: "mp3"
    },
    {
      headers: {
        "Authorization": `Bearer ${SUNO_API_KEY}`,
        "Content-Type": "application/json"
      }
    }
  );

  console.log(response.data);
}

generateSong();
```

# 🔐 5. **LICENSING NOTES (Important)**

Documentation states:

✔ **Watermark-free**
✔ **Commercial use allowed**
✔ **Royalty-free**
✔ **Shareable & redistributable**

BUT:

⚠️ *Avoid prompting the model to mimic known artists strictly (“sing like Beyoncé”).*
⚠️ Even commercial-allowed models can still trigger copyright issues if you force imitation.
⚠️ Use **generic styles** (e.g., “soft R&B”, “gentle soul”, “lo-fi pop”).

This keeps your app safe.
